FreshApp PrettyBlocks

Installation guide · version 1.3.1
Requirements: The PrettyBlocks module must be installed.

Installing the module

  1. In the back office, open Modules > Module Manager.
  2. Click Upload a module, at the top right of the screen.
  3. Drag the .zip file you downloaded after your purchase into the drop area, without unzipping it.
  4. Wait for the installation to finish, then click Configure.
You can reach the screen again at any time from the Configure button in the module manager.

After installation

The new blocks appear in the PrettyBlocks editor, in the list of available blocks: add them to your pages like any other block.

Full documentation

Find the module and its updates on the FreshApp.io shop:

https://shop.freshapp.io/en/

Updating: just drop the new archive through the same path. PrestaShop detects the version and runs the upgrade; your settings are kept.
